# Power allocation

Solar production and the all or nothing allocation over the mining, weapons and construction dials.

## Details

Port power.c: production from solar panels by daylight, demand per category, the 0 to 4 dial per
category, blackout when demand exceeds supply, and the effect on drills, turrets and construction.

Verification: Unit tests for production, the dials and blackout, a command based test that overloads and recovers.
