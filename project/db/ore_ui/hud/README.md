# HUD

The in game HUD with stock, power dials, wave timer and hints.

## Details

Port ui/hud.flecs and ui.c: the stock strip, the power dials with their segments, the wave
countdown, the score and the contextual hints, updated from the game components.

Verification: A visual scene at two surface sizes, a command based test reading the HUD after events.
