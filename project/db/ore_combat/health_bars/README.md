# Health bars

Health bars following buildings, critters and the player on screen.

## Details

Port health_bars.c onto the world anchored UI: a bar template anchored to its owner with the fill
from health, shown while damaged, in the game's colors.

Verification: Unit tests of the fill and visibility, a visual scene of damaged buildings.
