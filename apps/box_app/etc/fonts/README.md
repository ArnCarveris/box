# Fonts

`B612-Regular.ttf` is B612 Regular, Copyright 2012 The B612 Project Authors
(https://github.com/polarsys/b612), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). It is the fallback font SVG text falls back to when
no system font matches, and the only font the wasm build has.
