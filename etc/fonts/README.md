# Fonts

`B612-Regular.ttf` is B612 Regular 1.008, Copyright 2012 The B612 Project Authors
(https://github.com/polarsys/b612), licensed under the SIL Open Font License 1.1, see `OFL.txt`.

It ships in the framework `etc` folder, so the wasm build embeds it. A `Text` whose `font` is 0
uses it through the `box.text.DefaultFont` entity.
