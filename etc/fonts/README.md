# Fonts

`B612-Regular.ttf` is B612 Regular, Copyright 2012 The B612 Project Authors
(https://github.com/polarsys/b612), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org).

It ships with the framework `etc` folder, so it is installed at
`<BAKE_HOME>/etc/box/fonts` and is embedded in the wasm build. It is the font a
`Text` element uses when no `Font` names another one, and the fallback the SVG
rasterizer hands to resvg.
